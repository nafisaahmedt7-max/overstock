# FORM visual system

FORM uses a clinical monochrome catalog language: direct, product-led and deliberately undecorated. It borrows the restraint of contemporary fashion commerce without copying another brand's identity.

## Principles

1. Products are the content. Avoid lifestyle heroes and decorative imagery.
2. Use product cutouts with transparent backgrounds wherever possible.
3. Every element aligns to the grid. Borders define structure instead of cards or shadows.
4. Interface copy is short, uppercase and functional.

## Tokens

| Role | Token | Value |
|---|---|---|
| Ink | `--ink` | `#050505` |
| Page | `--paper` | `#f1f1ef` |
| Muted | `--muted` | `#777777` |
| UI type | `--font-mono` | Geist Mono |
| Display type | `--font-sans` | Geist |

## Product photography

- Export a transparent WebP or PNG with the entire product visible.
- Use a consistent 4:5 canvas and keep 8–12% breathing room around the product.
- Do not include mannequins, sets, text or baked-in backgrounds.
- Aim for 1600 × 2000 pixels and under 500 KB when practical.

## Layout

- Desktop catalog: three columns.
- Tablet catalog: two columns.
- Small mobile catalog: one column.
- Product pages split image and purchase information 2:1 on desktop.

## Voice

Use direct labels such as `ADD TO CART`, `SELECT SIZE` and `BY SELLER`. Avoid hype, vague slogans and unnecessary explanations.
